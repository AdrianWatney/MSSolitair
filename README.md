MS Visual Studio C++ Solitair 
You will need Microsoft Visual Studio to compile the C++ project
I scaned a pack of cards for the images, and then noticed its a German pack
The scanned images where done 10 at a time and then processed to make 1 file for each card they vary in size, you should be able to replace them with any scanned  images.
To place a card you can just click it, if it goes to the wrong stack you can drag and drop it to the stack you like.
This C++ code demonstrates a Solitair game to play on Windows.
